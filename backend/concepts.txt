<-------------------  why should we separate API from frontend ?  -----------------------> 
1- React --> Your Backend (API key stored here) --> NewsAPI.
2- In this way users cannot see your API key and can't exhaust its limit.
3- Imagine 1000 users came to your app then backend will call the api only once and store its result (caching).


~ backend ko frontend ke muqable me zada hit kiya jayega api ki waja se.
~ This application will be connected with Mongodb database and will store your notes permanently. 
~ rather than storing temporarily on local host (browser).


<-------------------  Postman or Thunder Client ?  -----------------------> 
1- thunder client and postman both used to test backend API's.
2- makes debugging super easy because no need to connect backend and frontend to test every api.
3- frontend code likhne ki zrurat nahi.
4- Thunder-Client is integrated with VsCode.


<-------------------------  End point   ---------------------------> 
1- Endpoint ek specific URL hota hai jahan frontend ya koi client backend se request bhejta hai aur   response leta hai.


<-------------------------  Get/Post Request  ---------------------------> 
1- Browser ya Thunder Client request bhejta hai.
2- Server request receive karta hai.
3- Zarurat ho to MongoDB se data leta ya save karta hai.
4- Phir server wapis browser ya thunder client ko response bhejta hai. 
5- Get Request is to fetch the data.
6- Post Request is to save the data.
